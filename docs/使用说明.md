# 音频切换器 · 使用说明

一个双击就能用的中文小工具:把 Windows 的**默认音频输出设备**在耳机、音响、虚拟声卡之间一键切换。

> **程序装在哪里**:`桌面\音频切换器\音频切换器.exe`(整个文件夹一起放着说明、源码和图标)。
> 开机启动项和桌面的「快速切换音频输出」快捷方式都指向这里,移动整个文件夹也没关系——程序下次启动会自动把开机启动项指回新位置。
> 本文档所在目录(`outputs`)里也有一份 exe,那只是**存档备份,平时不用点它**;真要重新安装或复制到别的电脑时用它。

- 免安装、绿色:就一个 `音频切换器.exe`,复制到哪都能用,删掉就干净。
- 不需要管理员权限,不写注册表,不常驻服务。
- 界面全中文;可以为**每台设备各绑一个按键**,也支持"一键切换"快捷键;关闭窗口后缩到右下角托盘继续待命。
- 按键可以是组合键(`Ctrl + Alt + S`),也可以是**单独一个键**(如 `F1`、小键盘 `1`)。

---

## 一、最常用:三步开始

1. 双击 `音频切换器.exe`,窗口会列出你电脑上所有**可用的播放设备**(就是 Windows 声音设置里"输出"那一栏能看到的那些)。
2. **双击**列表里的某一台设备,它立刻变成默认输出。也可以先单击选中,再点"设为默认"。
3. 之后按 **Ctrl + Alt + S**,就能在**最近用过的两台设备**之间来回切——比如音响和耳机,按一下切耳机,再按一下切回音响。

如果你更想"一个键直达一台设备",看第三节能把 `F1` 给音响、`F2` 给耳机,按下哪个就直接跳到哪台。

「当前输出」那一行、列表里的**实心圆点**和**加粗字体**,表示现在正在用的是哪一台。

## 二、托盘与快捷键

点窗口右上角的 ×,程序不会退出,而是缩到右下角托盘继续待命,快捷键照常可用。右键托盘图标:

| 菜单项 | 作用 |
| --- | --- |
| 打开切换窗口 | 把主窗口叫回来(双击托盘图标也一样) |
| 一键切换输出 | 和 Ctrl+Alt+S 同一个动作 |
| 创建桌面快捷方式(一键切换) | 在桌面生成"快速切换音频输出"图标,双击就直接切换并弹出提示 |
| 开机自动启动 | 勾选后开机自动静默驻留托盘 |
| 退出 | 真正关掉程序 |

> 建议先点一次"创建桌面快捷方式":以后不打开任何窗口,桌面双击一下就是一次切换,右下角会弹个小气泡告诉你切到了哪台设备。

## 三、给每个设备单独设一个按键(推荐)

除了"一键切换",还可以给**每台设备各绑一个按键**,按下就直接跳到那台设备——比如 `F1` 切音响、`F2` 切耳机。绑好之后,列表每行的右边会显示对应的按键标签:

1. 在列表里**选中**要设键的那台设备(例如"耳机");
2. 点上面的 **「给选中设备设按键」** 按钮,按钮会变成"请按组合键…";
3. 直接按下你想用的键即可。**可以只按一个键**(如 `F4`、小键盘 `1`、方向键),也可以按 `Ctrl + Alt + …` 组合。

**关于"单个按键"要提醒你一件事**:单独一个字母或数字(比如 `A`、`1`)会被系统**全局独占**——设好之后,你在任何程序里打字按到它,都会触发切换,那个字母也就打不出来了。所以程序会在你选这类键时弹窗确认一次。**建议用 `F1`–`F12`、小键盘数字、方向键这类平时不用的键。**

想**清除**某台设备的按键:选中它 → 点「给选中设备设按键」→ 按 `Backspace` 或 `Delete`。

## 四、改"一键切换"的快捷键

**在窗口里直接改(推荐)**:主界面底部有一行"快捷切换键",旁边就是当前的快捷键。点它一下,按钮会变成"请按组合键…",这时**直接按下你想要的组合键**即可,按对了立刻生效并存下来:

- 改的时候按 **Esc** = 取消,保持原来的键不变;
- 按 **Backspace** 或 **Delete** = 清除快捷键(以后就用按钮或托盘菜单切换);
- 单个按键同样支持(规则和上一节一样,选字母/数字时会先弹窗提醒);
- 如果提示"被别的程序占用了",说明这个组合被聊天工具、截图软件之类抢了,换一个再按一次。

可用的按键:字母 `A`–`Z`、数字 `0`–`9`、`F1`–`F24`、数字键盘 0–9 及 `* + - / .`、方向键、`Home`/`End`/`PageUp`/`PageDown`/`Insert`/`Delete`/`空格`/`Tab`。

**也可以改配置文件(进阶)**:快捷键存在下面这个文件里,直接用记事本改 `Hotkey=` 那一行、保存并重启程序,效果一样:

```
%APPDATA%\AudioOutputSwitcher\config.ini
```

> 说明:界面预览图里"音响 / 耳机"右边那两个 `F1`、`F2` 标签,就是第三节讲的"设备按键";新安装时默认是没有的,按你自己的习惯设就行。

## 五、命令行用法(可选,进阶)

在同一目录下打开终端,可以用参数直接调用,方便做成批处理或绑定到别的软件上:

```
音频切换器.exe --toggle          立刻在最近两台设备间切换,弹提示后退出
音频切换器.exe --toggle --quiet  同上,但不弹提示(适合脚本)
音频切换器.exe --set 耳机        按名称/序号切换到指定设备
音频切换器.exe --list            列出所有可用输出设备
音频切换器.exe --tray            只驻留托盘,不显示窗口(开机自启用的就是它)
```

## 六、可能遇到的情况

**切换后立刻又跳回原来的设备。**
多半是别的音频软件在接管默认设备——系统级音效软件(比如 SoundID Reference、Sonarworks 这类)、虚拟声卡驱动、或者声卡厂商的音效面板,都可能强行把自己设回默认输出。这种情况属于软件之间的抢占,不是切换器没生效;把那个软件的"跟随/接管默认设备"选项关掉即可。(你之前装的 SoundID Reference 已经卸载了,所以现在没有这个问题。)

**快捷键提示被占用。**
Ctrl+Alt+S 可能被聊天软件、截图工具的快捷键占了。按上面第三节改成别的组合。

**列表里有好几台名字一样的设备。**
Windows 用括号里的数字区分同名设备(例如"扬声器"和"扬声器 (2)"),那通常来自同一驱动装过两次或不同接口,选能出声的那台即可。名字下面的灰色小字是它属于哪块声卡。

**换台设备后没声音。**
说明那台设备本身没接东西(比如耳机没插)。插好设备后点一下"刷新",列表会重新读取。

**给设备设的键没反应。**
三种可能:一是那个键被别的程序占用了(改成别的键再试);二是设备被拔掉了(设备键只对当前插着的设备生效,插回来就恢复);三是设的是单个字母/数字,被别的程序优先吃掉了——这种情况建议换成 `F1`–`F12`。

**设完单个按键后,打字老是切设备。**
这就是"单个字母被全局独占"的后果,去列表里选中那台设备,点「给选中设备设按键」→ 按 `Backspace` 清除,然后改绑 `F1`–`F12` 之类不常用的键。

**Windows 弹出安全提示。**
这是个本地编译的绿色小工具,没有数字签名。若系统拦一下,选择"更多信息 → 仍要运行"即可。

## 七、说明

- 依赖系统自带的 .NET Framework 4.x,Win10 / Win11 都自带,无需另装。
- 程序只做一件事:调用 Windows 自身的音频接口切换默认播放设备,不碰音量、不碰音效设置。
- 如需重新编译(比如想自己改界面文字):源码在 `源码\AudioOutputSwitcher.cs`,在该目录下执行——
  ```
  C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe /optimize+ /platform:anycpu /win32icon:音频切换器.ico /out:..\音频切换器.exe /r:System.dll /r:System.Core.dll /r:System.Drawing.dll /r:System.Windows.Forms.dll AudioOutputSwitcher.cs
  ```
- 排查配置问题时,可运行 `音频切换器.exe --diag`,它会报告配置文件能写到哪。

## 更新记录

**2026-09-22 第二版**

- 修复:关到托盘后快捷键就失效的问题。原因是"隐藏窗口"时程序改动了窗口属性,导致热键所依附的窗口句柄被系统重建,热键随之丢失。现在热键固定注册在一个**独立的隐藏消息窗口**上,主窗口怎么显示/隐藏都不影响它。
- 修复:开机自启时可能"看起来没启动"。现在程序每 20 秒自检一次:音频设备还没就绪会自动重读;快捷键被别的启动程序抢先会**自动重试注册**;资源管理器重启后托盘图标会**自动补回来**。
- 新增:每台设备可以单独绑定一个按键,支持**单个按键**(如 `F1`、小键盘数字),不需要组合键。
- 新增:"一键切换"的按键可以直接在界面上录制修改。

## 附:清理重复的"扬声器 (2)"虚拟声卡

仓库的 `tools` 目录里还有一个配套的小工具:**`修复重复声卡.bat`**,用来处理 SoundID Reference 虚拟声卡被装了两份、导致声音设置里出现重复"扬声器 (2)"的问题。

1. 双击 `修复重复声卡.bat`,在弹出的用户账户控制窗口里选"是"(需要管理员权限才能改设备)。
2. 脚本会先列出检测到的虚拟声卡实例,以及每个实例对应的播放设备是"可用"还是"未接入(残留)"。
3. 输入 `1` 回车:脚本会**卸载多余的那个虚拟声卡实例**,并**清掉它残留在系统里的设备记录**,然后刷新音频服务,最后重新列一遍设备名给你看。
4. 之后打开 设置 → 系统 → 声音 → 所有声音设备,确认重复项是否消失;若还在,重启一次电脑再看。

> 为什么要"卸载 + 清记录"两步:只停用的话,那条残留记录还在,Windows 只要发现有重名,就会把 "(2)" 挂到正在使用的那台设备上——表现就是"开机时没有、过一会儿 SoundID 自启后又冒出来"。

几点说明:

- 操作是**可恢复**的:再次运行脚本输入 `2` 可把被停用的实例启用回来;被卸载的实例,在 SoundID Reference 里重新打开一次系统级处理(Systemwide)就会自动装回一个干净的。
- 脚本只处理驱动服务名里带 `soundid` / `sonarworks` 的设备,**不会碰**你的 Realtek、耳机、USB 声卡等其他任何设备。
- 如果脚本提示停用失败,可以打开"设备管理器 → 查看 → 显示隐藏的设备 → 声音、视频和游戏控制器",手动卸载多余的那个 SoundID Reference Virtual Audio Device。
- 只看状态不做改动:`powershell -File fix-duplicate-soundcard.ps1 -ScanOnly`
